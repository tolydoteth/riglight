# RigLight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows tray app that turns the PC's motherboard/case RGB and Corsair RAM RGB off/on in one click and sets color, effect and brightness for both, without opening iCUE or GIGABYTE Control Center.

**Architecture:** C++20 Win32 tray app. A pure, unit-tested core (`src/core`) holds the light state, settings format, software effect math, the Gigabyte Fusion2 packet scripts and the Corsair session state machine. Thin Windows units (`src/win`) execute those scripts over HID, drive the iCUE SDK DLL, and draw the tray icon and a Direct2D panel.

**Tech Stack:** C++20, MinGW-w64 g++ 15.2 (UCRT, posix threads), CMake ≥ 3.20 + Ninja, Win32 (SetupAPI/HID, Shell_NotifyIcon, Direct2D/DirectWrite, comdlg32), Corsair iCUE SDK v4.0.84 (`third_party/iCUESDK`, loaded at runtime).

**Spec:** `docs/superpowers/specs/2026-10-09-riglight-design.md`. Protocol reference: `docs/fusion2-protocol.md`.

## Global Constraints

- Repo: `C:\Users\tolik\Desktop\programming\riglight`. Build with `build.bat` (CMake + Ninja, Release, `-Wall -Wextra`, fully static exe like Keyflip).
- Namespace `rl` everywhere. Core (`src/core`) makes no Windows calls and is the only code under unit test.
- Never send Fusion2 commands `0x5E`, `0x47`, `0x33` or `0x34` (byte 1 of a packet). `fusion2::isForbidden` is checked before every HID write.
- Fusion2 packets are 64-byte feature reports, byte 0 = `0xCC`, on the HID collection VID `0x048D` PID `0x5711` UsagePage `0xFF89` Usage `0x00CC`.
- Zone map is used only when `HKLM\HARDWARE\DESCRIPTION\System\BIOS\BaseBoardProduct` (trimmed) equals `X870 EAGLE WIFI7` exactly.
- Brightness is an integer percent, clamped to 5–100. Defaults: on, warm white `FFB46B`, static, 60 %.
- Settings file: `%APPDATA%\RigLight\settings.ini` (keys `on`, `color`, `effect`, `brightness`). Autostart lives only in HKCU `Run` value `RigLight`.
- Every `CorsairLedColor` written has `a = 255`. SDK callbacks only `PostMessageW`; no `Corsair*` call inside a callback. `CorsairDisconnect` only at exit.
- No modal error dialogs. Status goes to the tray tooltip and the panel footer.
- Commit after every task (user rule: commit verified work without asking; no pushes).
- Live hardware steps: Claude can't see the lights — ask the user to confirm by eye.

## Review Focus

1. **Explorer restarts** (crash or update): the tray icon must come back by itself (`TaskbarCreated` message re-adds it) — Task 7, step "Explorer restart".
2. **Dragging the brightness slider** fires dozens of changes per second: device writes must be throttled to ≤ 25/s and the final value always applied — `ApplyThrottle` tests in Task 8.
3. **Hand-edited or corrupt `settings.ini`** (brightness 0 or 900, unknown effect, CRLF, missing keys): load must clamp/fall back, never crash — Settings tests in Task 1.
4. **iCUE closed or restarted while RigLight runs**: RAM shows "unavailable", then recovers by itself and re-applies when iCUE is back — CorsairSession tests in Task 4.
5. **Sleep/resume with lights off**: after resume both devices must be re-applied to "off", not left at firmware/iCUE defaults — CorsairSession `onResume` test in Task 4 and the live resume check in Task 9.

```cpp
#pragma once
#include <cstdio>
#include <string>

namespace check {
struct Test {
    const char* name;
    void (*fn)();
};
inline std::vector<Test>& registry() {
    static std::vector<Test> r;
    return r;
}
inline int& failures() {
    static int f = 0;
    return f;
}
struct Reg {
    Reg(const char* n, void (*f)()) { registry().push_back({n, f}); }
};
}  // namespace check

#define TEST(name)                                   \
    static void name();                              \
    static const check::Reg reg_##name(#name, name); \
    static void name()

#define CHECK(cond)                                                         \
    do {                                                                    \
        if (!(cond)) {                                                      \
            ++check::failures();                                            \
            std::printf("    FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); \
        }                                                                   \
    } while (0)

#define CHECK_EQ(a, b)                                                                  \
    do {                                                                                \
        const auto va_ = (a);                                                           \
        const auto vb_ = (b);                                                           \
        if (!(va_ == vb_)) {                                                            \
            ++check::failures();                                                        \
            std::printf("    FAIL %s:%d: %s == %s (%lld vs %lld)\n", __FILE__, __LINE__, \
                        #a, #b, (long long)va_, (long long)vb_);                        \
        }                                                                               \
    } while (0)

#define CHECK_STR(a, b)                                                                     \
    do {                                                                                    \
        const std::string va_(a);                                                           \
        const std::string vb_(b);                                                           \
        if (va_ != vb_) {                                                                   \
            ++check::failures();                                                            \
            std::printf("    FAIL %s:%d: %s == %s (\"%s\" vs \"%s\")\n", __FILE__, __LINE__, \
                        #a, #b, va_.c_str(), vb_.c_str());                                  \
        }                                                                                   \
    } while (0)
```

```cpp
#include <cstdio>
#include <cstring>

#include "check.h"

int main(int argc, char** argv) {
    const char* filter = argc > 1 ? argv[1] : nullptr;
    int ran = 0, failed = 0;
    for (const check::Test& t : check::registry()) {
        if (filter && !std::strstr(t.name, filter)) continue;
        const int before = check::failures();
        t.fn();
        ++ran;
        const bool ok = check::failures() == before;
        if (!ok) ++failed;
        std::printf("%s  %s\n", ok ? "ok  " : "FAIL", t.name);
    }
    std::printf("\n%d tests, %d failed\n", ran, failed);
    return failed == 0 && ran > 0 ? 0 : 1;
}
```

```cpp
#include "core/light_state.h"

#include <algorithm>
#include <cctype>

namespace rl {

int clampBrightness(int pct) { return std::clamp(pct, kMinBrightness, kMaxBrightness); }

const char* effectName(Effect e) {
    switch (e) {
        case Effect::Breathing: return "breathing";
        case Effect::Rainbow: return "rainbow";
        default: return "static";
    }
}

const char* effectLabel(Effect e) {
    switch (e) {
        case Effect::Breathing: return "Breathing";
        case Effect::Rainbow: return "Rainbow";
        default: return "Static";
    }
}

static std::string lower(std::string_view s) {
    std::string out(s);
    for (char& c : out) c = (char)std::tolower((unsigned char)c);
    return out;
}

std::optional<Effect> parseEffect(std::string_view s) {
    const std::string l = lower(s);
    if (l == "static") return Effect::Static;
    if (l == "breathing") return Effect::Breathing;
    if (l == "rainbow") return Effect::Rainbow;
    return std::nullopt;
}

std::string colorHex(Rgb c) {
    static const char* digits = "0123456789ABCDEF";
    std::string out;
    for (uint8_t v : {c.r, c.g, c.b}) {
        out += digits[v >> 4];
        out += digits[v & 15];
    }
    return out;
}

static int hexDigit(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'a' && c <= 'f') return c - 'a' + 10;
    if (c >= 'A' && c <= 'F') return c - 'A' + 10;
    return -1;
}

std::optional<Rgb> parseColorHex(std::string_view s) {
    if (!s.empty() && s.front() == '#') s.remove_prefix(1);
    if (s.size() != 6) return std::nullopt;
    uint8_t v[3];
    for (int i = 0; i < 3; ++i) {
        const int hi = hexDigit(s[2 * i]), lo = hexDigit(s[2 * i + 1]);
        if (hi < 0 || lo < 0) return std::nullopt;
        v[i] = (uint8_t)(hi * 16 + lo);
    }
    return Rgb{v[0], v[1], v[2]};
}

}  // namespace rl
```

`src/core/settings.cpp`:
```cpp
#include "core/settings.h"

#include <cctype>
#include <charconv>
#include <vector>

namespace rl {

static std::string_view trim(std::string_view s) {
    while (!s.empty() && std::isspace((unsigned char)s.front())) s.remove_prefix(1);
    while (!s.empty() && std::isspace((unsigned char)s.back())) s.remove_suffix(1);
    return s;
}

static std::string lowerStr(std::string_view s) {
    std::string out(s);
    for (char& c : out) c = (char)std::tolower((unsigned char)c);
    return out;
}

static std::optional<int> parseInt(std::string_view s) {
    s = trim(s);
    int v = 0;
    const auto [p, ec] = std::from_chars(s.data(), s.data() + s.size(), v);
    if (ec != std::errc{} || p != s.data() + s.size()) return std::nullopt;
    return v;
}

std::string serializeSettings(const LightState& s) {
    std::string out = "[lights]\n";
    out += std::string("on=") + (s.on ? "1" : "0") + "\n";
    out += "color=" + colorHex(s.color) + "\n";
    out += std::string("effect=") + effectName(s.effect) + "\n";
    out += "brightness=" + std::to_string(clampBrightness(s.brightness)) + "\n";
    return out;
}

LightState parseSettings(std::string_view text) {
    LightState s;
    size_t pos = 0;
    while (pos <= text.size()) {
        size_t end = text.find('\n', pos);
        if (end == std::string_view::npos) end = text.size();
        const std::string_view line = trim(text.substr(pos, end - pos));
        pos = end + 1;
        if (line.empty() || line[0] == ';' || line[0] == '#' || line[0] == '[') continue;
        const size_t eq = line.find('=');
        if (eq == std::string_view::npos) continue;
        const std::string key = lowerStr(trim(line.substr(0, eq)));
        const std::string_view val = trim(line.substr(eq + 1));
        if (key == "on") {
            if (val == "1") s.on = true;
            else if (val == "0") s.on = false;
        } else if (key == "color") {
            if (auto c = parseColorHex(val)) s.color = *c;
        } else if (key == "effect") {
            if (auto e = parseEffect(val)) s.effect = *e;
        } else if (key == "brightness") {
            if (auto b = parseInt(val)) s.brightness = clampBrightness(*b);
        }
    }
    return s;
}

static std::vector<std::string_view> split(std::string_view s, char sep) {
    std::vector<std::string_view> parts;
    size_t pos = 0;
    while (true) {
        const size_t end = s.find(sep, pos);
        parts.push_back(s.substr(pos, end == std::string_view::npos ? s.size() - pos : end - pos));
        if (end == std::string_view::npos) break;
        pos = end + 1;
    }
    return parts;
}

std::optional<LightState> parseStateSpec(std::string_view spec, const LightState& base) {
    const auto parts = split(trim(spec), ':');
    const std::string head = lowerStr(parts[0]);
    LightState s = base;
    if (head == "off" && parts.size() == 1) {
        s.on = false;
        return s;
    }
    if (head == "on" && parts.size() == 1) {
        s.on = true;
        return s;
    }
    s.on = true;
    if (head == "rainbow") {
        if (parts.size() > 2) return std::nullopt;
        s.effect = Effect::Rainbow;
        if (parts.size() == 2) {
            auto b = parseInt(parts[1]);
            if (!b) return std::nullopt;
            s.brightness = clampBrightness(*b);
        }
        return s;
    }
    if (head == "static" || head == "breathing") {
        if (parts.size() < 2 || parts.size() > 3) return std::nullopt;
        auto c = parseColorHex(parts[1]);
        if (!c) return std::nullopt;
        s.effect = head == "static" ? Effect::Static : Effect::Breathing;
        s.color = *c;
        if (parts.size() == 3) {
            auto b = parseInt(parts[2]);
            if (!b) return std::nullopt;
            s.brightness = clampBrightness(*b);
        }
        return s;
    }
    return std::nullopt;
}

}  // namespace rl
```

```cpp
#include "core/effects.h"

#include <algorithm>
#include <cmath>

namespace rl {

static uint8_t channel(double v) { return (uint8_t)std::clamp(std::lround(v), 0L, 255L); }

Rgb scaleColor(Rgb c, double f) {
    return Rgb{channel(c.r * f), channel(c.g * f), channel(c.b * f)};
}

Rgb cycleColor(int step) {
    const int n = timing::kCycleSteps;
    step = ((step % n) + n) % n;
    const double h = step * 360.0 / n;  // HSV with s = v = 1
    const int sector = (int)(h / 60.0) % 6;
    const double f = h / 60.0 - std::floor(h / 60.0);
    const double q = 1.0 - f, t = f;
    double r = 0, g = 0, b = 0;
    switch (sector) {
        case 0: r = 1; g = t; b = 0; break;
        case 1: r = q; g = 1; b = 0; break;
        case 2: r = 0; g = 1; b = t; break;
        case 3: r = 0; g = q; b = 1; break;
        case 4: r = t; g = 0; b = 1; break;
        default: r = 1; g = 0; b = q; break;
    }
    return Rgb{channel(r * 255), channel(g * 255), channel(b * 255)};
}

bool isAnimated(const LightState& s) { return s.on && s.effect != Effect::Static; }

static Rgb mix(Rgb a, Rgb b, double f) {
    return Rgb{channel(a.r + (b.r - a.r) * f), channel(a.g + (b.g - a.g) * f),
               channel(a.b + (b.b - a.b) * f)};
}

Rgb ramColorAt(const LightState& s, uint32_t tMs) {
    using namespace timing;
    if (!s.on) return Rgb{};
    const double pct = clampBrightness(s.brightness) / 100.0;
    switch (s.effect) {
        case Effect::Static:
            return scaleColor(s.color, pct);
        case Effect::Breathing: {
            const uint32_t p = tMs % kPulsePeriodMs;
            double f = 0;
            if (p < kPulseRiseMs) f = double(p) / kPulseRiseMs;
            else if (p < kPulseRiseMs + kPulseFallMs) f = 1.0 - double(p - kPulseRiseMs) / kPulseFallMs;
            return scaleColor(s.color, pct * f);
        }
        case Effect::Rainbow: {
            const int step = (int)((tMs / kCycleStepMs) % kCycleSteps);
            const uint32_t p = tMs % kCycleStepMs;
            Rgb c = cycleColor(step);
            if (p < kCycleFadeMs) c = mix(cycleColor(step - 1), c, double(p) / kCycleFadeMs);
            return scaleColor(c, pct);
        }
    }
    return Rgb{};
}

}  // namespace rl
```

```cpp
#include "core/fusion2.h"

#include <cstdio>

#include "core/effects.h"

namespace rl::fusion2 {

static void putU16(Packet& p, size_t at, uint16_t v) {
    p[at] = (uint8_t)(v & 0xFF);
    p[at + 1] = (uint8_t)(v >> 8);
}

static void putU32(Packet& p, size_t at, uint32_t v) {
    for (int i = 0; i < 4; ++i) p[at + i] = (uint8_t)((v >> (8 * i)) & 0xFF);
}

static uint32_t getU32(const Packet& p, size_t at) {
    return (uint32_t)p[at] | ((uint32_t)p[at + 1] << 8) | ((uint32_t)p[at + 2] << 16) |
           ((uint32_t)p[at + 3] << 24);
}

Packet command(uint8_t cmd, uint8_t arg0, uint8_t arg1) {
    Packet p{};
    p[0] = kReportId;
    p[1] = cmd;
    p[2] = arg0;
    p[3] = arg1;
    return p;
}

Report parseReport(const Packet& p) {
    Report r;
    r.valid = p[0] == kReportId;
    r.deviceNum = p[2];
    r.stripDetect = p[3];
    for (int i = 0; i < 4; ++i) r.fw[i] = p[4 + i];
    for (int i = 0; i < 3; ++i) r.argbCounts[i] = p[8 + i];
    r.supportCmdFlag = p[11];
    for (size_t i = 12; i < 40 && p[i] != 0; ++i) r.product += (char)p[i];
    r.chipId = getU32(p, 56);
    return r;
}

std::string describeReport(const Report& r) {
    char buf[256];
    std::snprintf(buf, sizeof buf,
                  "valid=%d product=\"%s\" fw=%u.%u.%u.%u device_num=%u strip_detect=%u "
                  "argb_counts=%02X %02X %02X support_cmd_flag=0x%02X (lamparray=%d) chip_id=0x%08X",
                  r.valid ? 1 : 0, r.product.c_str(), r.fw[0], r.fw[1], r.fw[2], r.fw[3],
                  r.deviceNum, r.stripDetect, r.argbCounts[0], r.argbCounts[1], r.argbCounts[2],
                  r.supportCmdFlag, r.lampArray() ? 1 : 0, r.chipId);
    return buf;
}

std::string hexDump(const Packet& p) {
    std::string out;
    char b[4];
    for (size_t i = 0; i < p.size(); ++i) {
        std::snprintf(b, sizeof b, "%02X", p[i]);
        out += b;
        out += (i % 16 == 15) ? '\n' : ' ';
    }
    return out;
}

bool isForbidden(const Packet& p) {
    const uint8_t c = p[1];
    return c == 0x5E || c == 0x47 || c == 0x33 || c == 0x34;
}

std::vector<Step> infoSteps() { return {Step{command(0x60), true, 0}}; }

std::vector<Step> probeSteps() {
    return {Step{command(0x60), true, 0}, Step{command(0x61), true, 0}};
}

std::vector<Step> initSteps(const Report& r) {
    std::vector<Step> v;
    if (r.lampArray()) v.push_back({command(0x48, 0x00)});  // LampArray (Dynamic Lighting) off
    for (uint8_t reg = 0x20; reg <= 0x27; ++reg) v.push_back({command(reg)});
    for (uint8_t reg = 0x90; reg <= 0x92; ++reg) v.push_back({command(reg)});
    v.push_back({command(0x28, 0xFF, 0x07)});  // apply all (5711 mask 0x07FF)
    v.push_back({command(0x31, 0x00)});        // audio "beat" mode off
    v.push_back({command(0x32, 0x00), false, 50});  // every ARGB header runs hardware effects
    return v;
}

Packet effectPacket(const Zone& z, const LightState& s) {
    using namespace rl::timing;
    Packet p{};
    p[0] = kReportId;
    p[1] = z.reg;
    putU32(p, 2, z.mask);
    uint8_t type = kEffectStatic, maxB = 0, param0 = 0;
    Rgb color{};
    uint16_t p0 = 0, p1 = 0, p2 = 0;
    const int pct = clampBrightness(s.brightness);
    const uint8_t b255 = (uint8_t)((pct * 255 + 50) / 100);
    if (s.on) {
        switch (s.effect) {
            case Effect::Static:
                maxB = b255;
                color = s.color;
                break;
            case Effect::Breathing:
                type = kEffectPulse;
                maxB = kPulseBrightnessIsPercent ? (uint8_t)pct : b255;
                color = s.color;
                p0 = (uint16_t)kPulseRiseMs;
                p1 = (uint16_t)kPulseFallMs;
                p2 = (uint16_t)kPulseHoldMs;
                break;
            case Effect::Rainbow:
                type = kEffectCycle;
                maxB = b255;
                p0 = (uint16_t)kCycleFadeMs;
                p1 = (uint16_t)kCycleHoldMs;
                param0 = (uint8_t)kCycleSteps;
                break;
        }
    }
    p[11] = type;
    p[12] = maxB;
    p[13] = 0;  // min brightness
    p[14] = color.b;
    p[15] = color.g;
    p[16] = color.r;
    putU16(p, 22, p0);
    putU16(p, 24, p1);
    putU16(p, 26, p2);
    p[30] = param0;
    return p;
}

std::vector<Step> applySteps(const LightState& s) {
    std::vector<Step> v;
    for (const Zone& z : kBoardZones) v.push_back({effectPacket(z, s)});
    Packet commit{};
    commit[0] = kReportId;
    commit[1] = 0x28;
    putU32(commit, 2, kBoardZoneMask);
    v.push_back({commit});
    return v;
}

}  // namespace rl::fusion2
```

```cpp
#include <iCUESDK/iCUESDK.h>

#include <string>

#include "core/light_state.h"

namespace rl {

// The iCUE SDK entry points, filled by GetProcAddress (win/sdk_loader) or by a test fake.
struct SdkApi {
    decltype(&CorsairConnect) connect = nullptr;
    decltype(&CorsairDisconnect) disconnect = nullptr;
    decltype(&CorsairGetDevices) getDevices = nullptr;
    decltype(&CorsairGetLedPositions) getLedPositions = nullptr;
    decltype(&CorsairSubscribeForEvents) subscribeForEvents = nullptr;
    decltype(&CorsairUnsubscribeFromEvents) unsubscribeFromEvents = nullptr;
    decltype(&CorsairRequestControl) requestControl = nullptr;
    decltype(&CorsairReleaseControl) releaseControl = nullptr;
    decltype(&CorsairSetLedColors) setLedColors = nullptr;
    bool complete() const;
};

struct Dimm {
    std::string id;
    std::string model;
    std::vector<CorsairLedColor> leds;  // ids from CorsairGetLedPositions
    bool controlled = false;
};

// Session + exclusive-control lifecycle for the RAM. Not thread-safe: the owner (win/corsair_ram)
// serialises every call with one mutex, and never calls it from inside an SDK callback.
class CorsairSession {
public:
    explicit CorsairSession(const SdkApi& api);

    CorsairError start(CorsairSessionStateChangedHandler onState, CorsairEventHandler onEvent, void* ctx);
    void onSessionState(CorsairSessionState state);
    void onDeviceConnected();  // a device (re)appeared: re-enumerate, re-take control, re-apply
    void onResume();           // after sleep: same as onDeviceConnected
    void onRetryTimer();       // re-request control for DIMMs that don't have it
    void apply(const LightState& s);                   // remember + write frame t = 0
    void writeFrame(const LightState& s, uint32_t tMs);  // animation thread, every frame
    void stop();               // release control, unsubscribe, disconnect (exit only)

    bool connected() const { return connected_; }
    bool available() const;
    bool needsRetry() const;
    const std::vector<Dimm>& dimms() const { return dimms_; }

private:
    void enumerate();
    void requestControl(Dimm& d);
    void writeColor(Rgb c);
    void reapply();

    SdkApi api_;
    CorsairEventHandler onEvent_ = nullptr;
    void* ctx_ = nullptr;
    bool started_ = false;
    bool connected_ = false;
    bool subscribed_ = false;
    bool haveState_ = false;
    LightState state_;
    std::vector<Dimm> dimms_;
};

}  // namespace rl
```

`src/core/corsair_session.cpp`:
```cpp
#include "core/corsair_session.h"

#include "core/effects.h"

namespace rl {

bool SdkApi::complete() const {
    return connect && disconnect && getDevices && getLedPositions && subscribeForEvents &&
           unsubscribeFromEvents && requestControl && releaseControl && setLedColors;
}

CorsairSession::CorsairSession(const SdkApi& api) : api_(api) {}

CorsairError CorsairSession::start(CorsairSessionStateChangedHandler onState, CorsairEventHandler onEvent,
                                   void* ctx) {
    onEvent_ = onEvent;
    ctx_ = ctx;
    const CorsairError e = api_.connect(onState, ctx);
    started_ = e == CE_Success;
    return e;
}

void CorsairSession::onSessionState(CorsairSessionState state) {
    if (state == CSS_Connected) {
        connected_ = true;
        subscribed_ = api_.subscribeForEvents(onEvent_, ctx_) == CE_Success;
        enumerate();
        reapply();
    } else {
        connected_ = false;
        subscribed_ = false;
        dimms_.clear();
    }
}

void CorsairSession::enumerate() {
    dimms_.clear();
    CorsairDeviceFilter filter{};
    filter.deviceTypeMask = CDT_MemoryModule;
    std::vector<CorsairDeviceInfo> infos(CORSAIR_DEVICE_COUNT_MAX);
    int n = 0;
    if (api_.getDevices(&filter, (int)infos.size(), infos.data(), &n) != CE_Success) return;
    std::vector<CorsairLedPosition> pos(CORSAIR_DEVICE_LEDCOUNT_MAX);
    for (int i = 0; i < n; ++i) {
        Dimm d;
        d.id = infos[i].id;
        d.model = infos[i].model;
        int count = 0;
        if (api_.getLedPositions(infos[i].id, (int)pos.size(), pos.data(), &count) == CE_Success) {
            for (int k = 0; k < count; ++k) d.leds.push_back(CorsairLedColor{pos[k].id, 0, 0, 0, 255});
        }
        requestControl(d);
        dimms_.push_back(std::move(d));
    }
}

void CorsairSession::requestControl(Dimm& d) {
    d.controlled = api_.requestControl(d.id.c_str(), CAL_ExclusiveLightingControl) == CE_Success;
}

void CorsairSession::writeColor(Rgb c) {
    for (Dimm& d : dimms_) {
        if (!d.controlled || d.leds.empty()) continue;
        for (CorsairLedColor& l : d.leds) {
            l.r = c.r;
            l.g = c.g;
            l.b = c.b;
            l.a = 255;
        }
        if (api_.setLedColors(d.id.c_str(), (int)d.leds.size(), d.leds.data()) == CE_NoControl)
            d.controlled = false;
    }
}

void CorsairSession::reapply() {
    if (haveState_) writeFrame(state_, 0);
}

void CorsairSession::onDeviceConnected() {
    if (!connected_) return;
    enumerate();
    reapply();
}

void CorsairSession::onResume() { onDeviceConnected(); }

void CorsairSession::onRetryTimer() {
    if (!connected_) return;
    bool gained = false;
    for (Dimm& d : dimms_) {
        if (d.controlled) continue;
        requestControl(d);
        gained = gained || d.controlled;
    }
    if (gained) reapply();
}

void CorsairSession::apply(const LightState& s) {
    state_ = s;
    haveState_ = true;
    writeFrame(s, 0);
}

void CorsairSession::writeFrame(const LightState& s, uint32_t tMs) {
    if (!connected_) return;
    writeColor(ramColorAt(s, tMs));
}

void CorsairSession::stop() {
    if (connected_) {
        for (Dimm& d : dimms_)
            if (d.controlled) api_.releaseControl(d.id.c_str());
        if (subscribed_) api_.unsubscribeFromEvents();
    }
    if (started_) api_.disconnect();
    started_ = connected_ = subscribed_ = false;
    dimms_.clear();
}

bool CorsairSession::available() const {
    if (!connected_) return false;
    for (const Dimm& d : dimms_)
        if (d.controlled) return true;
    return false;
}

bool CorsairSession::needsRetry() const {
    if (!connected_) return false;
    for (const Dimm& d : dimms_)
        if (!d.controlled) return true;
    return false;
}

}  // namespace rl
```

Note: `available()` is true when at least one DIMM is controlled; `needsRetry()` is true when any DIMM is not — both can be true at once.

```cpp
namespace rl {

std::vector<std::wstring> findHidCollections(uint16_t vid, uint16_t pid, uint16_t usagePage, uint16_t usage) {
    std::vector<std::wstring> out;
    GUID guid;
    HidD_GetHidGuid(&guid);
    HDEVINFO set = SetupDiGetClassDevsW(&guid, nullptr, nullptr, DIGCF_PRESENT | DIGCF_DEVICEINTERFACE);
    if (set == INVALID_HANDLE_VALUE) return out;
    SP_DEVICE_INTERFACE_DATA ifd{};
    ifd.cbSize = sizeof ifd;
    for (DWORD i = 0; SetupDiEnumDeviceInterfaces(set, nullptr, &guid, i, &ifd); ++i) {
        DWORD need = 0;
        SetupDiGetDeviceInterfaceDetailW(set, &ifd, nullptr, 0, &need, nullptr);
        if (need == 0) continue;
        std::vector<uint8_t> buf(need);
        auto* detail = reinterpret_cast<SP_DEVICE_INTERFACE_DETAIL_DATA_W*>(buf.data());
        detail->cbSize = sizeof(SP_DEVICE_INTERFACE_DETAIL_DATA_W);
        if (!SetupDiGetDeviceInterfaceDetailW(set, &ifd, detail, need, nullptr, nullptr)) continue;
        const std::wstring path = detail->DevicePath;
        // Access 0: enough to read attributes and caps, works even when another app has it open.
        HANDLE h = CreateFileW(path.c_str(), 0, FILE_SHARE_READ | FILE_SHARE_WRITE, nullptr, OPEN_EXISTING, 0, nullptr);
        if (h == INVALID_HANDLE_VALUE) continue;
        bool match = false;
        HIDD_ATTRIBUTES attr{};
        attr.Size = sizeof attr;
        if (HidD_GetAttributes(h, &attr) && attr.VendorID == vid && attr.ProductID == pid) {
            PHIDP_PREPARSED_DATA pre = nullptr;
            if (HidD_GetPreparsedData(h, &pre)) {
                HIDP_CAPS caps{};
                if (HidP_GetCaps(pre, &caps) == HIDP_STATUS_SUCCESS)
                    match = caps.UsagePage == usagePage && caps.Usage == usage;
                HidD_FreePreparsedData(pre);
            }
        }
        CloseHandle(h);
        if (match) out.push_back(path);
    }
    SetupDiDestroyDeviceInfoList(set);
    return out;
}
```

```cpp
Fusion2Device::Fusion2Device() : boardOk_(baseBoardProduct() == kBoardName) {}

bool Fusion2Device::run(HidDevice& dev, const std::vector<Step>& steps, std::vector<Packet>* reads) {
    for (const Step& s : steps) {
        if (isForbidden(s.bytes)) return false;  // never write flash, whatever the caller built
        if (!dev.setFeature(s.bytes)) return false;
        if (s.readAfter) {
            Packet r{};
            r[0] = kReportId;
            if (!dev.getFeature(r)) return false;
            if (reads) reads->push_back(r);
        }
        if (s.waitMs) Sleep(s.waitMs);
    }
    return true;
}

void Fusion2Device::close() {
    dev_.close();
    ready_ = false;
}

bool Fusion2Device::reinit() {
    close();
    if (!boardOk_) return false;
    const auto paths = findHidCollections(kVid, kPid, kUsagePage, kUsage);
    if (paths.empty() || !dev_.open(paths[0])) return false;
    std::vector<Packet> reads;
    if (!run(dev_, infoSteps(), &reads) || reads.empty()) {
        close();
        return false;
    }
    const Report report = parseReport(reads[0]);
    if (!report.valid || !run(dev_, initSteps(report), nullptr)) {
        close();
        return false;
    }
    ready_ = true;
    return true;
}

bool Fusion2Device::apply(const LightState& s) {
    if (!ready_ && !reinit()) return false;
    if (!run(dev_, applySteps(s), nullptr)) {
        close();
        return false;
    }
    return true;
}

bool Fusion2Device::matchesPath(const wchar_t* path) {
    if (!path) return false;
    std::wstring p(path);
    for (wchar_t& c : p) c = (wchar_t)std::towlower(c);
    return p.find(L"vid_048d&pid_5711&mi_01&col02") != std::wstring::npos;
}

std::string Fusion2Device::probe() {
    std::string out = "== Motherboard (Fusion2) ==\n";
    const std::string board = baseBoardProduct();
    out += "BaseBoardProduct: \"" + board + "\" (" + (board == kBoardName ? "supported" : "NOT supported") + ")\n";
    const auto paths = findHidCollections(kVid, kPid, kUsagePage, kUsage);
    out += "Control collections found: " + std::to_string(paths.size()) + "\n";
    for (const auto& p : paths) out += "  " + narrow(p) + "\n";
    if (paths.empty()) return out;
    HidDevice dev;
    if (!dev.open(paths[0])) {
        out += "open failed, error " + std::to_string(GetLastError()) + "\n";
        return out;
    }
    std::vector<Packet> reads;
    Fusion2Device self;
    const bool ok = self.run(dev, probeSteps(), &reads);
    out += std::string("probe script: ") + (ok ? "ok" : "FAILED") + "\n";
    if (!reads.empty()) {
        out += "CC 60 report: " + describeReport(parseReport(reads[0])) + "\n" + hexDump(reads[0]);
    }
    if (reads.size() > 1) out += "CC 61 calibration:\n" + hexDump(reads[1]);
    return out;
```

```cpp
void CorsairRam::onEventCb(void* ctx, const CorsairEvent* e) {
    if (e && e->id == CEI_DeviceConnectionStatusChangedEvent && e->deviceConnectionStatusChangedEvent &&
        e->deviceConnectionStatusChangedEvent->isConnected)
        PostMessageW(static_cast<HWND>(ctx), WM_APP_CORSAIR_DEVICE, 0, 0);
}

void CorsairRam::start() {
    sdk_ = loadCorsairSdk();
    if (!sdk_.module) return;  // RAM unavailable (missing DLL or VC++ runtime)
    {
        std::lock_guard lk(mu_);
        session_ = std::make_unique<CorsairSession>(sdk_.api);
        session_->start(&CorsairRam::onStateCb, &CorsairRam::onEventCb, hwnd_);
    }
    anim_ = std::thread([this] { animLoop(); });
}

void CorsairRam::animLoop() {
    std::unique_lock lk(mu_);
    while (!quit_) {
        if (!session_ || !isAnimated(state_)) {
            cv_.wait(lk);
            continue;
        }
        session_->writeFrame(state_, (uint32_t)(GetTickCount64() - t0_));
        cv_.wait_for(lk, std::chrono::milliseconds(timing::kFrameMs));
    }
}

void CorsairRam::apply(const LightState& s) {
    {
        std::lock_guard lk(mu_);
        state_ = s;
        t0_ = GetTickCount64();  // restart in step with the board's hardware effect
        if (session_) session_->apply(s);
    }
    cv_.notify_all();
}

}
```

```cpp
#include "core/icon.h"

#include <algorithm>
#include <cmath>

namespace rl {

static uint32_t premul(uint32_t rgb, double a) {
    const auto ch = [&](int shift) { return (uint32_t)std::lround(((rgb >> shift) & 0xFF) * a); };
    return ((uint32_t)std::lround(a * 255) << 24) | (ch(16) << 16) | (ch(8) << 8) | ch(0);
}

std::vector<uint32_t> bulbIconPixels(int size, bool on) {
    const double s = size;
    const double cx = s / 2, cy = s * 0.42, r = s * 0.33;
    const double ring = std::max(1.0, s / 14.0);  // outline width when off
    const double bx0 = s * 0.35, bx1 = s * 0.65, by0 = s * 0.76, by1 = s * 0.92;
    const uint32_t warm = 0xFFC24B, grey = 0x9A9A9A;
    std::vector<uint32_t> px((size_t)size * size, 0);
    const int sub = 4;  // 4x4 supersampling
    for (int y = 0; y < size; ++y)
        for (int x = 0; x < size; ++x) {
            int bulb = 0, base = 0;
            for (int sy = 0; sy < sub; ++sy)
                for (int sx = 0; sx < sub; ++sx) {
                    const double fx = x + (sx + 0.5) / sub, fy = y + (sy + 0.5) / sub;
                    const double d = std::hypot(fx - cx, fy - cy);
                    if (on ? d <= r : (d <= r && d >= r - ring)) ++bulb;
                    else if (fx >= bx0 && fx <= bx1 && fy >= by0 && fy <= by1) ++base;
                }
            const double n = sub * sub;
            if (bulb) px[(size_t)y * size + x] = premul(on ? warm : grey, bulb / n);
            else if (base) px[(size_t)y * size + x] = premul(grey, base / n);
        }
    return px;
}

}  // namespace rl
```

```cpp
namespace rl {

static const wchar_t* kRunKey = L"Software\\Microsoft\\Windows\\CurrentVersion\\Run";
static const wchar_t* kValue = L"RigLight";

bool autostartEnabled() {
    return RegGetValueW(HKEY_CURRENT_USER, kRunKey, kValue, RRF_RT_REG_SZ, nullptr, nullptr, nullptr) ==
           ERROR_SUCCESS;
}

bool setAutostart(bool on) {
    HKEY key;
    if (RegOpenKeyExW(HKEY_CURRENT_USER, kRunKey, 0, KEY_SET_VALUE, &key) != ERROR_SUCCESS) return false;
    LSTATUS rc;
    if (on) {
        wchar_t exe[MAX_PATH];
        GetModuleFileNameW(nullptr, exe, MAX_PATH);
        const std::wstring cmd = L"\"" + std::wstring(exe) + L"\"";
        rc = RegSetValueExW(key, kValue, 0, REG_SZ, reinterpret_cast<const BYTE*>(cmd.c_str()),
                            (DWORD)((cmd.size() + 1) * sizeof(wchar_t)));
    } else {
        rc = RegDeleteValueW(key, kValue);
        if (rc == ERROR_FILE_NOT_FOUND) rc = ERROR_SUCCESS;
    }
    RegCloseKey(key);
    return rc == ERROR_SUCCESS;
}

}  // namespace rl
```

```cpp
int App::run(const LightState& initial) {
    state_ = initial;
    WNDCLASSEXW wc{};
    wc.cbSize = sizeof wc;
    wc.lpfnWndProc = &App::wndProc;
    wc.hInstance = inst_;
    wc.lpszClassName = kHiddenClass;
    RegisterClassExW(&wc);
    // A hidden top-level window (not message-only): it must receive WM_POWERBROADCAST and
    // TaskbarCreated broadcasts.
    hwnd_ = CreateWindowExW(0, kHiddenClass, L"RigLight", WS_OVERLAPPED, 0, 0, 0, 0, nullptr, nullptr, inst_, this);
    if (!hwnd_) return 1;
    taskbarCreated_ = RegisterWindowMessageW(L"TaskbarCreated");

    DEV_BROADCAST_DEVICEINTERFACE_W filter{};
    filter.dbcc_size = sizeof filter;
    filter.dbcc_devicetype = DBT_DEVTYP_DEVICEINTERFACE;
    HidD_GetHidGuid(&filter.dbcc_classguid);
    devNotify_ = RegisterDeviceNotificationW(hwnd_, &filter, DEVICE_NOTIFY_WINDOW_HANDLE);

    const int iconSize = GetSystemMetrics(SM_CXSMICON);
    iconOn_ = makeBulbIcon(iconSize, true);
    iconOff_ = makeBulbIcon(iconSize, false);
    lights_ = std::make_unique<LightController>(hwnd_);

    tray_.add(hwnd_, state_.on ? iconOn_ : iconOff_, L"RigLight");
    refreshTray();
    SetTimer(hwnd_, kRetryTimerId, 10000, nullptr);

    MSG msg;
    while (GetMessageW(&msg, nullptr, 0, 0) > 0) {
        TranslateMessage(&msg);
        DispatchMessageW(&msg);
    }
    if (devNotify_) UnregisterDeviceNotification(devNotify_);
    DestroyIcon(iconOn_);
    DestroyIcon(iconOff_);
    return 0;

LRESULT CALLBACK App::wndProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {

    if (app && app->hwnd_) return app->handle(msg, wp, lp);
    return DefWindowProcW(hwnd, msg, wp, lp);

LRESULT App::handle(UINT msg, WPARAM wp, LPARAM lp) {
    if (msg == taskbarCreated_ && taskbarCreated_ != 0) {  // Explorer restarted
        tray_.add(hwnd_, state_.on ? iconOn_ : iconOff_, L"RigLight");
        refreshTray();
        return 0;
    }
    switch (msg) {
        case WM_APP_TRAY:
            switch (LOWORD(lp)) {
                case NIN_SELECT:
                case NIN_KEYSELECT: {
                    LightState s = state_;
                    s.on = !s.on;
                    changeState(s);
                    return 0;
                }
                case WM_CONTEXTMENU:
                    showMenu(POINT{GET_X_LPARAM(wp), GET_Y_LPARAM(wp)});
                    return 0;
            }
            return 0;
        case WM_COMMAND:
            switch (LOWORD(wp)) {
                case IDM_TOGGLE: {
                    LightState s = state_;
                    s.on = !s.on;
                    changeState(s);
                    return 0;
                }
                case IDM_AUTOSTART:
                    setAutostart(!autostartEnabled());
                    return 0;
                case IDM_QUIT:
                    quit();
                    return 0;
            }
            return 0;
        case WM_APP_RELOAD:
            if (auto text = readTextFile(settingsPath())) changeState(parseSettings(*text));
            return 0;
        case WM_APP_CORSAIR_SESSION:
            lights_->onCorsairSession((int)wp);
            refreshTray();
            return 0;
        case WM_APP_CORSAIR_DEVICE:
            lights_->onCorsairDevice();
            refreshTray();
            return 0;
        case WM_TIMER:
            if (wp == kRetryTimerId) {
                lights_->onRetryTimer();
                refreshTray();
            }
            return 0;
        case WM_POWERBROADCAST:
            if (wp == PBT_APMRESUMEAUTOMATIC) {
                lights_->onResume();
                refreshTray();
            }
            return TRUE;
        case WM_DEVICECHANGE: {
            auto* hdr = reinterpret_cast<DEV_BROADCAST_HDR*>(lp);
            if (hdr && hdr->dbch_devicetype == DBT_DEVTYP_DEVICEINTERFACE) {
                auto* di = reinterpret_cast<DEV_BROADCAST_DEVICEINTERFACE_W*>(lp);
                if (wp == DBT_DEVICEARRIVAL) lights_->onDeviceArrival(di->dbcc_name);
                else if (wp == DBT_DEVICEREMOVECOMPLETE) lights_->onDeviceRemoval(di->dbcc_name);
                refreshTray();
            }
            return TRUE;
        }
        case WM_QUERYENDSESSION:
            return TRUE;
        case WM_ENDSESSION:
            if (wp) quit();
            return 0;
        case WM_DESTROY:
```

```cpp
PanelHitResult panelHitTest(const PanelLayout& l, float x, float y) {
    if (l.power.contains(x, y)) return {PanelHit::Power, -1};
    for (int i = 0; i < 8; ++i)
        if (l.swatches[i].contains(x, y)) return {PanelHit::Swatch, i};
    if (l.custom.contains(x, y)) return {PanelHit::Custom, -1};
    for (int i = 0; i < 3; ++i)
        if (l.effects[i].contains(x, y)) return {PanelHit::Effect, i};
    if (l.slider.contains(x, y)) return {PanelHit::Slider, -1};
    return {};
}

int sliderValueAt(const PanelLayout& l, float x) {
    const float f = std::clamp((x - l.track.x) / l.track.w, 0.0f, 1.0f);
    return clampBrightness(kMinBrightness + (int)std::lround(f * (kMaxBrightness - kMinBrightness)));
}

float sliderKnobX(const PanelLayout& l, int pct) {
    const float f = float(clampBrightness(pct) - kMinBrightness) / (kMaxBrightness - kMinBrightness);
    return l.track.x + f * l.track.w;
}

int swatchIndexOf(Rgb c) {
    for (int i = 0; i < (int)kSwatches.size(); ++i)
        if (kSwatches[i] == c) return i;
    return -1;
}

RectI placePanel(RectI icon, RectI work, int w, int h) {
    const int m = 12;
    const bool known = icon.right > icon.left && icon.bottom > icon.top;
    const int icx = (icon.left + icon.right) / 2, icy = (icon.top + icon.bottom) / 2;
    int x = work.right - m - w, y = work.bottom - m - h;  // default: bottom-right corner
    if (known) {
        if (icon.top >= work.bottom) {  // taskbar at the bottom
            x = icx - w / 2;
            y = work.bottom - m - h;
        } else if (icon.bottom <= work.top) {  // top
            x = icx - w / 2;
            y = work.top + m;
        } else if (icon.left >= work.right) {  // right
            x = work.right - m - w;
            y = icy - h / 2;
        } else if (icon.right <= work.left) {  // left
            x = work.left + m;
            y = icy - h / 2;
        }
    }
    x = std::clamp(x, work.left + m, work.right - m - w);
    y = std::clamp(y, work.top + m, work.bottom - m - h);
    return RectI{x, y, x + w, y + h};
}

bool ApplyThrottle::request(uint64_t now) {
    if (!any_ || now - last_ >= interval_) {
        any_ = true;
        last_ = now;
        pending_ = false;
        return true;
    }
    pending_ = true;
    return false;
}

bool ApplyThrottle::flushDue(uint64_t now) {
    if (pending_ && now - last_ >= interval_) {
        last_ = now;
        pending_ = false;
        return true;
    }
    return false;
}
```

```cpp
void Panel::show(RECT iconRect, const LightState& s, bool mbOk, bool ramOk) {
    state_ = s;
    mbOk_ = mbOk;
    ramOk_ = ramOk;
    HMONITOR mon = MonitorFromRect(&iconRect, MONITOR_DEFAULTTOPRIMARY);
    MONITORINFO mi{};
    mi.cbSize = sizeof mi;
    GetMonitorInfoW(mon, &mi);
    // Size for the monitor that holds the icon (the window may currently sit on another one).
    UINT mdpiX = 96, mdpiY = 96;
    using GetDpiForMonitorFn = HRESULT(WINAPI*)(HMONITOR, int, UINT*, UINT*);

        FreeLibrary(shcore);

    const int w = (int)std::lround(layout_.width * sc), h = (int)std::lround(layout_.height * sc);

                                                    D2D1::PixelFormat(), dpi, dpi);
    return SUCCEEDED(factory_->CreateHwndRenderTarget(
        props, D2D1::HwndRenderTargetProperties(hwnd_, D2D1::SizeU(rc.right, rc.bottom)), &rt_));
}

void Panel::releaseTarget() { release(rt_); }

void Panel::paint() {
    if (!ensureTarget()) return;
    const Theme t = currentTheme();
    const bool on = state_.on;
    const bool rainbow = state_.effect == Effect::Rainbow;
    ID2D1SolidColorBrush* b = nullptr;
    rt_->CreateSolidColorBrush(t.text, &b);
    auto fill = [&](D2D1_COLOR_F c) { b->SetColor(c); return b; };
    auto text = [&](const std::wstring& s, const RectF& r, IDWriteTextFormat* f, D2D1_COLOR_F c) {
        rt_->DrawTextW(s.c_str(), (UINT32)s.size(), f, toD2D(r), fill(c));
    };

    rt_->BeginDraw();
    rt_->Clear(t.bg);
    text(L"RigLight", layout_.title, titleFmt_, t.text);

    // Power pill
    const RectF& p = layout_.power;
    const auto pill = D2D1::RoundedRect(toD2D(p), p.h / 2, p.h / 2);
    if (on) {
        rt_->FillRoundedRectangle(pill, fill(t.accent));
    } else {
        rt_->FillRoundedRectangle(pill, fill(t.control));
        rt_->DrawRoundedRectangle(pill, fill(t.border), 1.0f);
    }
    const float kr = p.h / 2 - 4;
    const float kx = on ? p.x + p.w - p.h / 2 : p.x + p.h / 2;
    rt_->FillEllipse(D2D1::Ellipse(D2D1::Point2F(kx, p.y + p.h / 2), kr, kr), fill(on ? hex(0xFFFFFF) : t.subtle));

    const float dim = on ? 1.0f : 0.45f;
    text(L"Color", layout_.colorLabel, textFmt_, t.subtle);
    const int sel = rainbow ? -2 : swatchIndexOf(state_.color);
    for (int i = 0; i < 8; ++i) {
        const RectF& r = layout_.swatches[i];
        const Rgb c = kSwatches[i];
        const auto e = D2D1::Ellipse(D2D1::Point2F(r.x + r.w / 2, r.y + r.h / 2), r.w / 2 - 2, r.h / 2 - 2);
        rt_->FillEllipse(e, fill(D2D1::ColorF(c.r / 255.0f, c.g / 255.0f, c.b / 255.0f, (rainbow ? 0.35f : 1.0f) * dim)));
        rt_->DrawEllipse(e, fill(t.border), 1.0f);
        if (sel == i)
            rt_->DrawEllipse(D2D1::Ellipse(e.point, r.w / 2 + 1, r.h / 2 + 1), fill(t.accent), 2.0f);
    }
    {
        const RectF& r = layout_.custom;
        const auto e = D2D1::Ellipse(D2D1::Point2F(r.x + r.w / 2, r.y + r.h / 2), r.w / 2 - 2, r.h / 2 - 2);
        if (sel == -1) {
            const Rgb c = state_.color;
            rt_->FillEllipse(e, fill(D2D1::ColorF(c.r / 255.0f, c.g / 255.0f, c.b / 255.0f, dim)));
            rt_->DrawEllipse(D2D1::Ellipse(e.point, r.w / 2 + 1, r.h / 2 + 1), fill(t.accent), 2.0f);
        } else {
            rt_->FillEllipse(e, fill(t.control));
            rt_->DrawEllipse(e, fill(t.border), 1.0f);
            text(L"+", r, centerFmt_, rainbow ? t.border : t.text);
        }
    }

    text(L"Effect", layout_.effectLabel, textFmt_, t.subtle);
    const wchar_t* names[3] = {L"Static", L"Breathing", L"Rainbow"};
    const RectF all{layout_.effects[0].x, layout_.effects[0].y, layout_.effects[2].x + layout_.effects[2].w - layout_.effects[0].x,
                    layout_.effects[0].h};
    rt_->FillRoundedRectangle(D2D1::RoundedRect(toD2D(all), 6, 6), fill(t.control));
    for (int i = 0; i < 3; ++i) {
        const RectF& r = layout_.effects[i];
        const bool active = (int)state_.effect == i;
        if (active)
            rt_->FillRoundedRectangle(D2D1::RoundedRect(D2D1::RectF(r.x + 2, r.y + 2, r.x + r.w - 2, r.y + r.h - 2), 5, 5),
                                      fill(D2D1::ColorF(t.accent.r, t.accent.g, t.accent.b, dim)));
        text(names[i], r, centerFmt_, active ? hex(0xFFFFFF) : t.text);
    }

    const int pct = clampBrightness(state_.brightness);
    text(L"Brightness   " + std::to_wstring(pct) + L"%", layout_.brightnessLabel, textFmt_, t.subtle);
    const RectF& tr = layout_.track;
    const float kxs = sliderKnobX(layout_, pct);
    rt_->FillRectangle(D2D1::RectF(tr.x, tr.y - 1, tr.x + tr.w, tr.y + tr.h + 1), fill(t.border));
    rt_->FillRectangle(D2D1::RectF(tr.x, tr.y - 1, kxs, tr.y + tr.h + 1),
                       fill(D2D1::ColorF(t.accent.r, t.accent.g, t.accent.b, dim)));
    const auto knob = D2D1::Ellipse(D2D1::Point2F(kxs, tr.y + tr.h / 2), 8, 8);
    rt_->FillEllipse(knob, fill(hex(0xFFFFFF)));
    rt_->DrawEllipse(knob, fill(t.border), 1.0f);

    text(widen(footerText(mbOk_, ramOk_)), layout_.footer, textFmt_, t.subtle);

    if (rt_->EndDraw() == D2DERR_RECREATE_TARGET) releaseTarget();
    b->Release();
}

void Panel::emit() {
    if (onChange_) onChange_(state_);
}

void Panel::click(float x, float y) {
    const PanelHitResult h = panelHitTest(layout_, x, y);
    switch (h.kind) {
        case PanelHit::Power:
            state_.on = !state_.on;
            emit();
            break;
        case PanelHit::Swatch:
            if (state_.effect == Effect::Rainbow) return;  // colors are disabled for rainbow
            state_.color = kSwatches[h.index];
            state_.on = true;
            emit();
            break;
        case PanelHit::Custom:
            if (state_.effect == Effect::Rainbow) return;
            pickCustom();
            return;
        case PanelHit::Effect:
            state_.effect = (Effect)h.index;
            state_.on = true;
            emit();
            break;
        case PanelHit::Slider:
            dragging_ = true;
            SetCapture(hwnd_);
            dragTo(x, false);
            return;
        case PanelHit::None:
            return;
    }
    InvalidateRect(hwnd_, nullptr, FALSE);
}

void Panel::dragTo(float x, bool final) {
    state_.brightness = sliderValueAt(layout_, x);
    state_.on = true;
    const uint64_t now = GetTickCount64();
    if (final) {
        emit();  // the last value always goes out
    } else if (throttle_.request(now)) {
        emit();
    } else {
        SetTimer(hwnd_, kThrottleTimerId, 15, nullptr);
    }
    InvalidateRect(hwnd_, nullptr, FALSE);
}

void Panel::pickCustom() {
    static COLORREF custom[16] = {};
    CHOOSECOLORW cc{};
    cc.lStructSize = sizeof cc;
    cc.hwndOwner = hwnd_;
    cc.rgbResult = RGB(state_.color.r, state_.color.g, state_.color.b);
    cc.lpCustColors = custom;
    cc.Flags = CC_FULLOPEN | CC_RGBINIT;
    inDialog_ = true;  // keep the panel open while the dialog has focus
    const BOOL ok = ChooseColorW(&cc);
    inDialog_ = false;
    if (ok) {
        state_.color = Rgb{GetRValue(cc.rgbResult), GetGValue(cc.rgbResult), GetBValue(cc.rgbResult)};
        state_.on = true;
        emit();
    }
    SetForegroundWindow(hwnd_);
    InvalidateRect(hwnd_, nullptr, FALSE);
}

LRESULT CALLBACK Panel::wndProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    if (msg == WM_NCCREATE) {
        auto* cs = reinterpret_cast<CREATESTRUCTW*>(lp);
        SetWindowLongPtrW(hwnd, GWLP_USERDATA, (LONG_PTR)cs->lpCreateParams);
        reinterpret_cast<Panel*>(cs->lpCreateParams)->hwnd_ = hwnd;
    }
    auto* self = reinterpret_cast<Panel*>(GetWindowLongPtrW(hwnd, GWLP_USERDATA));
    return self ? self->handle(msg, wp, lp) : DefWindowProcW(hwnd, msg, wp, lp);
}

LRESULT Panel::handle(UINT msg, WPARAM wp, LPARAM lp) {
    const float sc = scale();
    switch (msg) {
        case WM_PAINT: {
            PAINTSTRUCT ps;
            BeginPaint(hwnd_, &ps);
            paint();
            EndPaint(hwnd_, &ps);
            return 0;
        }
        case WM_SIZE:
            if (rt_) rt_->Resize(D2D1::SizeU(LOWORD(lp), HIWORD(lp)));
            return 0;
        case WM_DPICHANGED:
            releaseTarget();
            return 0;
        case WM_ACTIVATE:
            if (LOWORD(wp) == WA_INACTIVE && !inDialog_) hide();
            return 0;
        case WM_KEYDOWN:
            if (wp == VK_ESCAPE) hide();
            return 0;
        case WM_LBUTTONDOWN:
            click(GET_X_LPARAM(lp) / sc, GET_Y_LPARAM(lp) / sc);
            return 0;
        case WM_MOUSEMOVE:
            if (dragging_) dragTo(GET_X_LPARAM(lp) / sc, false);
            return 0;
        case WM_LBUTTONUP:
            if (dragging_) {
                dragging_ = false;
                ReleaseCapture();
                KillTimer(hwnd_, kThrottleTimerId);
                dragTo(GET_X_LPARAM(lp) / sc, true);
            }
            return 0;
        case WM_TIMER:
            if (wp == kThrottleTimerId && throttle_.flushDue(GetTickCount64())) {
                KillTimer(hwnd_, kThrottleTimerId);
                emit();
            }
            return 0;
    }
    return DefWindowProcW(hwnd_, msg, wp, lp);
}
```
